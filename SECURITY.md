# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/KingPin/FanOut/security/advisories/new).

You should receive a response within 7 days. If the issue is confirmed, a fix
will be released and credited in the advisory unless you prefer otherwise.
